# VPN 连接问题排障指南（Windows）

## 症状
- VPN 客户端连接时报错误 809（最常见）
- VPN 频繁断连（每 10-30 分钟一次）
- 一直卡在"正在连接"无法建立隧道
- 能连上但无法访问内网系统

## 诊断步骤
1. 查询系统状态：确认 vpn-gateway 服务是否 degraded、是否有活跃故障（INC）
2. 查询近期变更：客户端强制升级类变更会导致旧版本无法连接（如错误 809）
3. 确认客户端版本：GlobalProtect 版本必须 >= 7.2.3（2026-10 变更 CHG-339 起强制）
4. 确认网络环境：公司网络 / 家庭网络，是否经过企业防火墙
5. 确认 MFA 状态：登录 VPN 需要通过 MFA 验证，MFA token 过期会导致认证失败

## 解决步骤
1. 若系统状态显示已知故障（如 INC-1042 上海出口拥塞）：告知用户等待恢复，无需处理
2. 若为错误 809 且客户端版本 < 7.2.3：升级 GlobalProtect 客户端至 7.2.3 以上后重连
3. 检查证书：证书过期时删除旧证书并重新连接，客户端会自动拉取新证书
4. 重置网络栈：管理员权限运行 `netsh winsock reset` 后重启电脑
5. 以上无效时重装客户端：控制面板卸载后从software.acme.com重新下载安装

## 何时升级人工
- MFA token 过期 / MFA 设备丢失：Agent 不能重置 MFA，必须转人工核验身份后重置
- 排查完客户端版本、证书、网络栈后仍无法连接：可能是网关侧问题，转网络组
- 用户在客户现场或出差且时间紧急：可建议先用手机热点验证是否办公网问题，仍失败则升级
